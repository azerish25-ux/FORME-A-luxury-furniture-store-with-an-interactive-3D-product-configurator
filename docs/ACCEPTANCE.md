# Acceptance and evidence

The repository's validation suite covers pure domain helpers, JSON/section schemas, rendering of the real Liquid templates against fixture data, and Playwright shopping interactions. GitHub Actions produces browser screenshots, a JSON report, traces for failures, and an HTML report. Inspect the actual run status rather than treating the presence of a test file as a pass.

## Automated cases

All 36 exact variant combinations; size/upholstery pricing; sold-out configuration preservation; unknown-ID fallback; quantity boundaries; share-link safety; comparison limits and injection guards; homepage images and console errors; selective model loading; size/material/dimension controls; rapid model-response races; failed 3D fallback; shared configuration and correct cart subtotal; unavailable product rejection; cart quantity/removal; filter/search/empty states; comparison persistence; sample-product simulated order; newsletter simulation disclosure; mobile navigation/overflow; serious/critical axe issues.

## Human/store acceptance still required

Install as an unpublished Shopify theme and import/review the fictional catalogue. Check native Shopify Liquid output, actual product IDs, all media, configured filters, shipping/tax rules, unavailable inventory, test gateway success and failure, actual order confirmation and order line IDs. Record a merchant changing the product price/image and Theme Editor content without code. Review screen-reader announcements, touch gestures, reduced-motion behaviour, multiple browser/GPU classes, image realism and real delivery/legal policies. The portfolio simulator is explicitly not proof of any of these Shopify platform results.
